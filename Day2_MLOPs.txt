     |

     |

     |

     |

Model Management : 
4 main components :

1. Model Registry - Centralized repository for registered models and their versions
2. Model Versioning - Same model - maintaining different versions
3. Model Lifecycle - model stages developing, testing, production
4. Model Promotion - Move model from one stage or env to another after validation


Current workflow : model version tags and aliases - separate registered models for deployment, staging and production environment

Tags : 

Awaiting validation -> Tag: validation_status=pending
Approved for production -> Tag: approval_status=approved
Production-serving version -> Alias : champion

Image - can then be used to create container or compatible container platforms
